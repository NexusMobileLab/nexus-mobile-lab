# NEXUS GUARDIAN v0.3 Android Project

## Build
This is an Android WebView project. The included GitHub Actions workflow builds a debug APK.

1. Upload the contents of this folder to a GitHub repository (not the ZIP itself).
2. Open the repository's Actions tab.
3. Run "Build NEXUS GUARDIAN APK" using Run workflow, or push to main.
4. Download the `NEXUS-GUARDIAN-v0.3-debug` artifact from the completed workflow.

The current version contains the MIYA image and expression/status demo controls.
Microphone, real AI responses, and true facial/eye animation are not connected yet.
